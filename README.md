# Desktop Replacement — Release

Questo repository contiene solo gli APK firmati di Desktop Replacement.

Il codice sorgente sta in un repository privato. Scarica l'ultima versione
dalla pagina delle release: ogni release allega l'APK e il file `.sha256`
con l'hash da verificare.

Verifica del download:

```bash
shasum -a 256 -c DesktopReplacement-<versione>.apk.sha256
```
